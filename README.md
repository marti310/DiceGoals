# Dice Goals
* Based on [this paper](https://arxiv.org/abs/) by [Christoph Koutschan]() and [Lucy Martinez](https://marti310.github.io/ "Lucy")

## Usage    
Example using DiceGoals.txt.
* Save the file: ``DiceGoals.txt``. Use ``DiceGoals.txt`` and stay in the same directory. Get into Mape and type:

  ``` read `DiceGoals.txt:` ```

* The following will be prompted

```
        First Written: November 2025: tested for Maple 20
                  Version of Jan., 2006:

    This is DiceGoals.txt, a Maple package, accompanying the article:
    How Many Dice Rolls Does It Take to Achieve Your Prescribed Goal?
                  by Christoph Koutschan and Lucy Martinez

            This Maple package, as well as the article, are 
                        available from:
                            WEBSITE

          Please report bugs to lucy.martinez@rutgers.edu

                -----------------------------


             For a list of the procedures type Help(); 
     for help with a specific procedure, type Help(procedure_name)

           For a list of the supporting functions type: Help1();

                 -----------------------------

  For a list of the recurrence package provided by Zeilberger type HelpRec(); 
      for help with a specific procedure, type HelpRec(procedure_name)

                 -----------------------------

   For a list of the faster procedures and recurrences type HelpFast(); 
     for help with a specific procedure, type Help(procedure_name)

                 -----------------------------

   For a list of the simulation procedures type HelpSimu(); 
 for help with a specific procedure, type Help(procedure_name)

                 -----------------------------


```
